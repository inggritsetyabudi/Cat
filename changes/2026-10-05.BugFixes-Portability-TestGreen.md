#### AIR Lowerer (`claw/src/ir/air.cpp`)
- Removed duplicate `BorrowExpr` handling block in `emitExprValue()` (the second block was dead code)
- Restructured `emitExprValue` fallthrough to correctly dispatch `IndexExpr` after `BorrowExpr`

#### LLVM Codegen (`claw/src/codegen/llvm_internal.h`)
- Simplified `stripViewPrefix()`: removed duplicate `ref[` / `ref mut[` conditions
- New order: `ref mut[`, `ref[`, `ref mut `, `ref `, `look `, `edit `

#### Codegen Target Triple (`claw/src/codegen/llvm_emit.cpp`)
- Replaced hardcoded `"x86_64-w64-windows-gnu"` with platform-aware detection:
  - macOS Intel: `x86_64-apple-darwin`
  - macOS ARM64: `aarch64-apple-darwin`
  - Windows: `x86_64-w64-windows-gnu`
  - Linux Intel: `x86_64-unknown-linux-gnu`
  - Linux ARM64: `aarch64-unknown-linux-gnu`
  - Fallback: `x86_64-unknown-unknown`

#### Driver — MSYS Path Guard (`claw/src/driver/main.cpp`)
- Wrapped `maybeConvertMsysPath()` in `#if defined(_WIN32)`
- On non-Windows (macOS/Linux), function returns `{}`, preventing POSIX path corruption

#### Native Build — Cross-Platform Clang Invocation (`claw/src/driver/native_build.cpp`)
- Replaced Windows-only `<process.h>`, `_wspawnvp()`, `_getpid()`, `_P_WAIT` with conditional compilation
- `#if defined(_WIN32)` → Windows path with `_wspawnvp`
- `#else` → POSIX path with `std::system("clang ...")` 
- `makeTempLlPath()`: `_getpid()` → `getpid()` (POSIX) / `_getpid()` (Windows)

#### Runtime — macOS Symbol Prefix + Slice/Buffer ABI (`claw/runtime/native_runtime.c`)
- Added `CLAW_RT_ASM` macro for platform-aware symbol naming:
  - macOS: `_claw.runtime.xxx` (prefix `_`)
  - Windows: `claw.runtime.xxx` (no prefix)
- Changed all `print/println` symbols to use the macro
- Changed `claw_runtime_print_slice()` and `claw_runtime_println_slice()` to accept `const claw_slice*` (pointer) instead of `claw_slice` (by value), matching LLVM IR caller expectation of passing `ptr` parameter
- Same pointer change for `claw_runtime_print_buffer()` and `claw_runtime_println_buffer()`
- Added null-safety guards in print functions

#### Test Script — llvm-as Fallback (`claw/tests/backend/run_backend_tests.sh`)
- Added fallback: if `llvm-as` not found, use `clang -x ir -c` instead
- Makes backend test suite portable across macOS (no llvm-as in default PATH)
