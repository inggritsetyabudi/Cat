## Rujukan §§11–20 tanpa label ganda

Koreksi ini menelusuri seluruh aturan dan penutup risiko §§11–20. Rujukan berikut sengaja tidak memperoleh label kedua; pemilik kanonik pada tabel tetap satu. Ini bukan klaim bahwa korpus PRD di luar lingkup tersebut sudah exhaustive atau bahwa gerbang G2 ditutup.

- **§11 L484:** matriks suffix-versus-separator merujuk `G2-PRD-11-SUFFIX`, `SUFFIX-FALLBACK`, `SUFFIX-INVALID`, dan `SUFFIX-CANONICAL`. Contoh exact `0xFF_fLoAt32`, `0xFF_F`, `0xAB_cD`, `1_iNt8`, dan `1_0` adalah matriks pengujian aturan itu, bukan lima label fitur. Label unary fneg lama `G2-PRD-11-FLOAT` dihapus karena §11 tidak menyatakan aturan unary; bukti fneg existing tidak dibantah atau dipromosikan menjadi bukti literal. **§12:** label index byte lama `G2-PRD-12-STR-INDEX` tidak memiliki aturan normatif index scalar pada bagian ini; immutable/static storage tetap dilacak terpisah, dan slicing byte tetap §14.
- **§13 L533/L540:** `parseTypeParameterList` menerima `with` sesuai pemilik `G2-PRD-13-WITH`/`WITH-KEYWORD`; mulai satu constraint lalu `and` adalah dimensi staging pemilik `WITH`/`WITH-AND`, bukan penerimaan parser. Contoh Add[Vector2] hanya mendukung tipe kontrak generic penuh; ia tidak menetapkan hukum operator overloading.
- **[§16 L614–619](PRD.md#16-sinkronisasi-dua-prd):** otoritas PRD panjang dimiliki `G2-PRD-16-SOURCE`. «Dokumen ringkas tidak ditulis tangan lagi, tetapi dibuat otomatis dari baris `Ringkas:`» dan normalisasi UTF-8 L615 merujuk `G2-PLAN-G7`. Contoh main Int32 dengan return 0 serta penandaan main Unit sebagai varian sah L616 merujuk `G2-PLAN-G6`.
