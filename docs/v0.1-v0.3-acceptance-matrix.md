- **Staged/tidak didukung:** dialokasikan ke milestone K lain atau dibatasi SPEC.
- **Blocked:** PR terbuka atau isu yang diketahui menghalangi klaim penerimaan.

## Bukti integrasi dan batas saat ini

- **Positif:** empat fixture (`composition_core.cat`, `composition_workspace/`, `composition_ownership_ranges.cat`, `composition_implicit_result.cat`) dengan **20 target execution** ber-output exact: `driverO2`, `relinkO0`, `relinkO2`, `sanitizerO0`, `sanitizerO2` per fixture. Runner wajib mempertahankan `check`, LLVM, native build, wrapper `@main`, stdout exact, dan artefak hanya di `claw/tests/integration/artifacts/`.
- **Batas positif ownership:** mencakup `String.as_str()` untuk view/slicing/get dan owned String dalam choice. Owned choice hasil sementara diikat ke local binding sebelum `pick`. Borrowed `Str` dalam tuple serta penggabungan view dari owner berbeda tidak didukung dan tidak diselundupkan ke fixture positif; ini batas implementasi, bukan fitur yang diklaim lulus.
- **Negatif:** `claw/tests/integration/run_negative_composition_tests.py`, **13 fixture × 4 = 52** pemeriksaan. Setiap penolakan harus cocok dengan **header diagnostik lengkap dan source span**, exit non-zero, stdout kosong, serta tanpa LLVM/executable/artifact; termasuk borrowed shape field dan owned tuple projection/partial move.
- **Oracle:** `claw/tests/integration/run_pattern_oracle.py`, **100 kasus deterministik**, seed **`0xC0FFEE`** (`12648430`), **44 accepted, 56 rejected, dan 13 build/run native** dengan stdout exact. Matcher independen mencakup tag choice dan struktur nested tuple dengan binding/wildcard (bukan partisi literal Bool/Int atau seluruh grammar pattern); termasuk empat regresi catch-all ganda. Ini bukan bukti exhaustiveness umum.
- **Compiler sanitizer:** job CI Linux `linux-sanitizers` menjalankan full suite dengan `ASAN_OPTIONS=detect_leaks=1:halt_on_error=1` dan `UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1`; instrumentasi compiler terpisah dari target sanitizer. **Full clean final local Release/sanitizer suite PASS.** CI Linux Release, Linux compiler sanitizer, dan Windows UCRT64 wajib pada head yang sama; status dan tautan run final dicatat pada [PR25](https://github.com/inggritsetyabudi/Cat/pull/25), bukan diasumsikan dari hasil lokal.

**Defect kombinasi terkonfirmasi:** baseline `80a4a20` menolak implicit tail `Ok(value + 1)` setelah `val value = try read(flag)` dalam fungsi `Result[Int32, String]` sebagai `Undefined variable: Ok`, meskipun explicit `return Ok(...)` diterima. Konteks tipe return kini diteruskan juga ke implicit value tail ber-return choice (Result/Maybe/custom), dengan jalur numerik biasa tetap seperti sebelumnya. Ini perbaikan implementasi aturan v0.2 yang sudah didokumentasikan, bukan syntax baru; fixture `composition_implicit_result.cat` mencakup sukses/gagal Result, Some/None, serta choice pengguna sebagai regresi permanen.
