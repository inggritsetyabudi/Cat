# v0.2 — Nilai minimum integer signed

Sebelumnya magnitude literal diperiksa sebagai bilangan positif sebelum unary minus diterapkan, sehingga `-2147483648` ditolak ketika bertipe `Int32`.

Sema kini memakai batas magnitude negatif khusus untuk operand integer langsung di bawah unary minus, termasuk literal bersuffix. Batas literal positif tidak dilonggarkan: `2147483648` bertipe `Int32` tetap ditolak. Lowering unary integer menghasilkan operasi integer native.

Tes: frontend menerima `-2147483648`, menolak kontrol positif `2147483648`, dan native suite menjalankan program yang mencetak `-2147483648`.

Verifikasi akhir: clean build seluruh target dan full test suite berhasil.
