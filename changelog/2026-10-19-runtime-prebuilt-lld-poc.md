# 2026-10-19 — PoC runtime Int32 prebuilt dengan LLVM/LLD23.1.3

Menambahkan `CLAW_ENABLE_RUNTIME_POC`, default **OFF**, sebagai eksperimen packaging terpisah yang membutuhkan LLVM C++ dan LLD PoC. Backend, source runtime C, ABI dan semantik produksi tidak berubah. Tidak ada promosi production, release, versi/tag, merge atau marker PRD.

Audit runtime asli dan emitter produksi mengidentifikasi `claw.runtime.println.i32` dengan ABI C `void(i32)`. Adapter hanya membuka hook `runtime.println` untuk satu `Int32` dan hasil `Unit` melalui opt-in `--runtime-i32`, tanpa metadata external/builtin/result binding. Collision simbol runtime dan metadata malformed ditolak. Default 41 kasus lama tidak diubah, termasuk penolakan runtime tanpa flag. Unit test adapter ditambah, bukan mengganti oracle lama.

Persiapan CMake mengompilasi `native_runtime.c` produksi yang utuh dan tidak dimodifikasi, sekali per target/configuration jika dibutuhkan build system, ke object native dan archive statik tersendiri. Target ini bukan dependency executable produksi. Manifest memuat hash/mtime/ukuran source/object/archive, compiler/target/flags, archive members, format native, simbol dan lisensi repo. Linux dibatasi GCC13/Ubuntu24 x86_64 ELF; Windows dibatasi GNU-target MinGW UCRT x64, dengan Clang exact23.1.3 atau GNU UCRT yang lolos pemeriksaan native/CRT. Tidak ada SDK LLVM18 atau fallback compiler/linker pada jalur PoC.

Gerbang baru memakai lima source Cat nyata untuk output0,42,Int32 maksimum, helper Unit, mutable scalar, dan beberapa println. Setiap stdout/stderr/exit dibandingkan dengan oracle eksplisit dan executable produksi. Preparation serta pembanding produksi memakai toolchain normal; emisi object dan link/run baru memakai lingkungan terisolasi tanpa compiler C/Clang/cc di PATH. External LLD exact23.1.3 hanya menerima native object, archive prebuilt dan input CRT/SDK eksplisit; tidak menerima source `.cat`, `.ll` atau runtime `.c`. Hash/mtime input runtime tidak boleh berubah per source. Sepuluh warm run mencatat waktu emit/link/run dan memverifikasi output, bukan benchmark kemenangan seluruh compiler.

Tes tambahan menolak runtime default, Str literal, String owned, Bool dan print; negative link menguji archive tidak disertakan, simbol tidak tersedia, archive malformed dan file archive hilang tanpa executable stale. Target ELF/PE, triple/DataLayout, defined/undefined/import symbols, GC dan dependency executable diaudit. Kontrak konfigurasi memastikan default OFF tidak membutuhkan compiler C dan kombinasi opsi yang tidak lengkap gagal.

**Berhenti pada Int32.** Scalar plain tidak mempunyai ownership/drop Cat; stdio/startup CRT masih dapat mengalokasikan secara internal. Archive lengkap berisi runtime owned, tetapi section GC harus menghilangkan fungsi owned yang tidak dirujuk dari output. Tidak ada klaim dukungan layout `{ptr,len}` Str, `{ptr,len,cap}` String, leak/double-free/drop parity, arithmetic signed baru, seluruh overload, FFI, MSVC, MSVCRT, Apple, ARM64 atau cross-compilation. Runtime Cat statik bukan CRT statik atau paket hermetik.

Linux configure/build paket dan gerbang runtime telah dijalankan saat implementasi. Penerimaan platform/CI harus mengikuti exact SHA dan hasil gate native yang sebenarnya, bukan sekadar konfigurasi atau CI PoC OFF. Suite produksi, sanitizer host, PTY dan oracle diagnostik baseline Windows tetap dipertahankan. Bila diagnostik lama masih menghasilkan `0xC0000005` alih-alih stack-overflow yang dituntut oracle, laporkan terpisah dan jangan menyebut seluruh CI hijau.
