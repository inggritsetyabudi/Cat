# 2026-10-11 — v0.1 module graph and share boundaries

Moved cycle detection ahead of the already-loaded-unit cache lookup, so a recursive import now fails rather than silently reusing a unit still on the load stack. Export type catalogs now contain only imported public types and locally `share`d shapes/choices; private types referenced by a shared shape or function signature produce an unknown-type diagnostic. Added negative fixtures for a real two-file cycle, private type leakage, and importing an unshared function.

Validation: a clean temporary CMake build and the complete doc-test, frontend, OIR, backend, and native suites passed. A separate native build/run of two same-suffix `math` modules under different namespaces succeeded with aliases and printed `42` and `22`. No Arena files or behavior were changed, and no commit or push was made.
