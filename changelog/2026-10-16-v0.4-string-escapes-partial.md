# Escape string biasa untuk PRD §12 / v0.4 (2026-10-16)

Slice ini menyelaraskan escape **ordinary quoted string** dengan kontrak escape `Char` PRD §11 dan aturan “Escape string sama dengan Char” pada PRD §12. PRD kanonis dan status milestone tidak diubah.

## Kontrak yang diimplementasikan

- Literal string biasa menerima `\n`, `\t`, `\r`, `\\`, `\"`, `\'`, `\0`, dan `\u{hex}`.
- Kutip ganda yang di-escape tidak menutup token. Escape Unicode harus berisi digit hex dan kurung kurawal penutup; scalar surrogate serta nilai di atas U+10FFFF ditolak. Scalar valid di-encode sebagai UTF-8.
- Decoder bersama dipakai oleh lexer dan backend; lexer menolak escape tidak dikenal, malformed, UTF-8 mentah invalid, backslash terminal, kutip tak tertutup, dan raw line break dengan diagnostic pada span token sumber.
- Backend menghasilkan byte string sesuai hasil decoding. Embedded NUL tetap length-aware; tidak ada perubahan runtime atau API string.
- F-string dan `///` documentation tidak disentuh; raw multiline string biasa tidak ditambahkan.

## Reproduksi baseline sebelum perubahan

Baseline dibangun dan dijalankan dari `origin/main` pada `b756b987a67c7ea449d76f9eedc4e2f6ce9a60a9` sebelum source diedit:

- String dengan `\"` gagal saat build: lexer menutup string terlalu awal, lalu parser melaporkan `Expected ')' after arguments` pada `escaped_quote.cat:2:23`.
- Escape tidak dikenal `\q` diterima; executable baseline mencetak `q` (backslash dibuang).
- `\u{41}` diterima tetapi executable baseline mencetak teks `u{41}` alih-alih scalar `A`.
- String `A\0B` memiliki `Str.len() == 3` dan runtime mencetak byte `41 00 42`; karena storage/runtime sudah length-aware, tidak diperlukan perubahan NUL/API.

## Regresi dan verifikasi

- Fixture frontend positif mencakup escape kontrol, kedua jenis quote, backslash, NUL, `\u{41}`, emoji mentah dan escaped, serta string kosong.
- Fixture negatif mencakup unknown escape; Unicode escape kosong, malformed, tanpa `}`, surrogate, dan di atas U+10FFFF; backslash terminal; string tak tertutup; serta raw newline. Tes span pada literal berisi UTF-8 `é` sebelum escape memastikan posisi kolom `:2:20` dan panjang token enam byte.
- Fixture native membandingkan stdout sebagai byte persis: `41 22 27 5c 0a 09 0d 00 f0 9f 98 80 f0 9f 98 80 21 0a`; tes juga memeriksa panjang string termasuk NUL. LLVM IR memuat global emoji UTF-8 `[9 x i8]` dengan terminator NUL.
- Build compiler dan suite frontend lulus. Native exact-byte/LLVM assertions serta executable hasil LLVM IR di bawah ASan/UBSan/LSan lulus.
- Build bersih dan `bash tests/run_all_tests.sh` lulus seluruh doc-test, frontend, OIR, backend, native/sanitizer, dan CLI suite pada salinan disposable `/tmp/Cat-string-escape-consistency-full-20261016`. Log tersimpan di `/tmp/Cat-string-escape-consistency-full-20261016/all-tests.log`.
- Independent read-only review tidak menemukan bug atau blocker.
