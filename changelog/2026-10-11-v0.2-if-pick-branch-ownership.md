# 2026-10-11 — Ownership merge berdasarkan reachability

## Temuan

Repro awal: pada `val x = "outer"; val y = if flag { return x } else { "inner" }; return y`, state branch yang sudah terminal ikut masuk ke merge `IfExpr`. Akibatnya, drop `x` tidak tercatat pada satu-satunya jalur `else` yang masih mencapai return.

## Perbaikan

Ownership checker kini melacak reachability, menandai `return` sebagai terminal, dan menyatukan state hanya dari branch yang dapat mencapai kelanjutan. Bila satu cabang terminal dan satu cabang hidup, state cabang hidup dipertahankan; bila keduanya terminal, tidak ada continuation ownership. Logika branch serupa diterapkan pada `if`/`pick` statement dan expression.

## Verifikasi

- OIR menunjukkan `drop x : Str` sesudah `if_join` sebelum `return y`; branch `return x` tidak menjatuhkan nilai yang telah dipindahkan.
- Native output `inner` lalu `outer` memastikan nilai yang dipilih tetap benar.
- Mirror regression memakai `Anchor[Str]` untuk membuat cleanup teramati; LeakSanitizer/AddressSanitizer lulus untuk hasil dari kondisi `false` dan `true`, sehingga kasus ini bukan hanya OIR snapshot.
- Clean build dan full test suite lulus pada salinan disposable.
