## Nested Scoped Generic Support

### Cakupan
Nested scoped type `Box[Name[s]]` kini didukung end-to-end, melanjutkan direct scoped-type propagation. Konstruktor generic memerlukan expected concrete type, misalnya `val box: Box[Name[s]] = Box { ... }`; generic type inference tanpa konteks tipe sengaja tidak ditebak.

### Implementasi
- Semantic analysis memakai substitusi field generic rekursif sehingga provenance scope di `Name[s]` tetap melekat di dalam `Box[T]`.
- Binder yang sama pada parameter nested harus memetakan ke satu scope aktual. Mismatch binder/field, return yang membawa scope lokal keluar, dan generic literal tanpa expected type ditolak.
- LLVM membentuk concrete aggregate type dari tipe field yang telah disubstitusi, menyelesaikan layout/alignment per instansiasi, dan menurunkan parameter, return, call, serta field access. Fixture besar dengan `Int128` memaksa indirect aggregate ABI dan memverifikasi jalur return-slot/argument-address.
- Ekspor shared/imported untuk generic shape serta signature nested scoped diuji melalui workspace lintas modul. Scope tetap keputusan semantik dan tidak menjadi identitas lifetime di LLVM.

### Regression Coverage dan Validasi
| Area | Bukti validasi |
|---|---|
| Frontend positif | `Box[Name[s]]` melalui konstruktor bertipe, identity/selection call, return, serta akses nested field |
| Frontend negatif | Dua scope aktual untuk binder yang sama; scope field tidak cocok dengan expected type; nested return escape; generic literal tanpa expected type |
| Backend LLVM | Verifikasi LLVM IR untuk instantiated aggregate layout, alignment 16, indirect parameter/return ABI, calls, dan GEP field access |
| Native langsung | Program nested generic berhasil dibangun dan mencetak `alpha` |
| Workspace/native | Generic shape dan signature nested scoped shared/imported berhasil dibangun dan mencetak `workspace` |
| Suite/build | CMake/Ninja build, seluruh frontend/backend LLVM/native test suites, serta `git diff --check` lulus |

### Batas
Perubahan ini tidak menambah general lifetime inference. Generic shape literal tetap membutuhkan expected concrete type; klaim dukungan dan coverage berfokus pada nested scoped generic seperti `Box[Name[s]]`, bukan semua pola generic atau semua strategi inferensi yang mungkin.
