# Bounded language reference (2026-10-17)

**Status:** documentation-only addition at implementation baseline `6b17b68`; not a frozen v1 specification or PRD amendment.

## Changes

Added [SPEC.md](../SPEC.md) as a practical reference for naming, scalar aliases, literals and escapes, bindings, initialization, ownership, functions, supported operator precedence, shapes/choices/tuples, arrays/ranges, UTF-8 string views, Result/Maybe/try, and file-based modules. It states the exact shorthand-versus-local-handler try distinction and the absence of a required `modules.cat` index. Unsupported casts and general collection/aggregate support are not advertised.

Outputs were inspected for arithmetic, fixed arrays/ranges/UTF-8 views, and Result propagation/pick. Relative links and the module anchor passed validation. The clean Linux Release build and complete repository runner passed, including canonical PRD positive/negative doc-tests.

## Boundary
