# 2026-10-11 — v0.1 file modules and folder namespaces

Replaced folder publication through `modules.cat`/`pub modules` with path-based module discovery: each `.cat` file is a module, directories form namespaces, and `share` remains the item visibility boundary. Removed the manifest parser and legacy lexer keywords, migrated all non-Arena workspace fixtures away from manifest files, and added module-path aliases (`import src.math as ...`) to make same-suffix modules unambiguous. `import super.{ ... }` remains supported for one-level siblings.

Validation baseline before this slice: clean CMake build and the full compiler test entrypoint passed against the then-current local tree, including workspace tests that still used `modules.cat`. After this slice, another clean temporary build and the complete doc-test, frontend, OIR, backend, and native suites all passed. Arena implementation and fixtures were not changed; no commit or push was made.
