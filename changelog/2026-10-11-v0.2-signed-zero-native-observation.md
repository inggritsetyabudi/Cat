# v0.2 — Observasi signed zero pada native runtime

Perbandingan `==` tidak membedakan `-0.0` dari `+0.0`. Penelusuran tidak menemukan primitive `signbit`, `copysign`, `to_bits`, atau bit reinterpretation. PRD §6 hanya memasukkan `/` dalam tabel presedensi/grup A; PRD tidak menetapkan hasil pembagian float dengan nol, jadi `fdiv` tidak dipakai sebagai oracle.

Native Cat sudah menyediakan observer lewat `println(Float32/Float64)`: bundled runtime mengirim nilai ke `fprintf` dengan format `%.9g` dan `%.17g`. Probe Cat native menghasilkan `-0` untuk hasil unary negation dari nol positif dan `0` untuk nol positif, pada kedua tipe. Fixture sekarang menguji output tersebut sebagai bagian dari test native, selain membandingkan hasil angka biasa.

Ekspektasi test: `1`, `-0`, `0`, `-0`, `0` (Float64 lalu Float32). Tidak ada perubahan compiler atau semantik pembagian. Pemeriksaan ini secara sengaja terbatas pada formatter native yang saat ini dibundel; PRD belum menjanjikan format teks float yang sama lintas-backend.

Verifikasi terarah: fixture Cat lolos `claw check`, native build berhasil, dan output cocok persis dengan ekspektasi di atas.

Verifikasi akhir: test Cat native terarah lulus dengan output tepat `1\n-0\n0\n-0\n0`; `bash claw/tests/run_all_tests.sh` dan `git diff --check` juga lulus.
