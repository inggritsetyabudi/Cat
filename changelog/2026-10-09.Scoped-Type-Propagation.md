## Scoped Type Propagation

### Kontrak
`Name[s]` pada view shape kini dikenali sebagai tipe yang membawa scope, bukan sebagai generic type argument biasa. Nama scope yang muncul pada signature fungsi menjadi binder formal; saat call, binder dipetakan ke scope aktual yang aktif. Binder yang sama pada beberapa parameter harus menunjuk scope aktual yang sama. Return scoped harus terikat pada parameter, dan parameter owned/tidak scoped tidak dapat menjadi sumber bagi borrow yang diklaim hidup selama scope pemanggil.

Scope mismatch, return scope yang tidak terikat, escape, dan sumber dengan lifetime terlalu pendek tetap ditolak.

### Implementasi dan Safety
`TypeCatalog` kini menyimpan metadata view shape dan mengumpulkan binder/sumber scoped return dalam `FunctionSignature`. Semantic analyzer menginstansiasi scope pada call, menyediakan formal scope saat menganalisis body, memeriksa provenance/lifetime, serta mempertahankan metadata pada binding dan hasil call. Metadata yang sama dibawa melalui shared/imported signature workspace. Borrowed aggregate tetap ditolak pada field ordinary shape dan payload `Anchor`; validasi Anchor recursive juga menolak scoped payload.

### Regression Coverage dan Validasi

| Area | Bukti validasi |
|---|---|
| Frontend positif | `ref[borrow]`, `PairView[borrow]`, field access yang mengembalikan scoped ref, dan binder formal yang berbeda nama dari scope aktual |
| Frontend negatif | Scope mismatch untuk ref dan `Name[s]`, argumen tanpa scope aktual, binder return berbeda/tidak terikat, lifetime terlalu pendek, serta scoped aggregate pada ordinary shape dan `Anchor` |
| Workspace/native | Shared view shape dan scoped function signatures lintas modul berhasil di-build dan dijalankan; output `workspace` |
| Native langsung | Scoped ref dan `Name[s]` melalui parameter/return berhasil di-build dan dijalankan; output `alpha` |
| Suite/build | CMake/Ninja build, seluruh frontend/backend LLVM/native suites, dan `git diff --check` lulus |

Patch native-runtime lokal yang sudah ada tetap dipertahankan; regresi runtime discovery turut lulus.
