# 2026-10-11 — Propagasi kelanjutan all-`Never`

## Temuan

Repro sebelum perbaikan: `claw check` menerima initializer `if`/`pick` dengan seluruh cabang berakhir lewat `return`, tetapi OIR kemudian membuat `val ...: Never = unit` dan meneruskan instruksi berikutnya; native build gagal saat LLVM menurunkan `Never`.

## Perbaikan

- `OirValue` membawa status eksplisit bahwa expression lowering tidak memiliki continuation.
- `IfExpr`/`PickExpr` memulangkan status terminal bila tidak ada branch yang mencapai join; scrutinee/kondisi dan operand terminal juga menghentikan lowering pemanggil.
- Binding, return, assignment, statement, dan block lowering tidak lagi mengeluarkan binding atau operasi setelah expression terminal.
- Termination predicate sema/OIR mengenali initializer/assignment bertipe `Never` agar block-value inference dan CFG tidak menganggapnya fallthrough.

## Verifikasi

Fixture native memuat `terminal_if_initializer` dan `terminal_pick_initializer`, masing-masing diikuti `println` yang tidak boleh diturunkan. OIR golden hanya berisi branch dan `return` pada cabang; tidak berisi binding `Never` atau panggilan setelah cabang. Clean native compile melalui full suite lulus, begitu pula seluruh frontend, OIR, backend, dan native suite di salinan disposable.

Integrasi bentuk sumber `defect` tidak termasuk perubahan ini karena grammar-nya belum diputuskan.
