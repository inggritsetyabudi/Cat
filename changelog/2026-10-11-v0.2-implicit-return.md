# v0.2 — Implicit return pada ekor blok

Implementasi slice implicit return: hanya ekspresi terakhir dalam blok nilai yang memasok nilai blok/return implisit. Ekspresi bernilai non-ekor tetap dievaluasi sebagai statement dan nilainya diabaikan; compiler mengeluarkan `warning[semantic]` nonfatal. Blok fungsi tanpa nilai ekor yang sesuai tetap ditolak, sehingga ekspresi tengah tidak dapat menggantikan `return` yang hilang.

Peringatan mencakup blok fungsi dan blok cabang bernilai `if`/`pick`. Ekspresi `Unit`, `Never`, tipe yang belum diketahui, serta nilai must-use yang sudah memiliki diagnostik error khusus tidak diberi warning duplikat.

## Validasi awal slice implicit return

- Clean configure/build CMake dari salinan disposable.
- Frontend: fixture positif memeriksa warning nonfatal; fixture negatif membuktikan ekspresi tengah tidak memenuhi return fungsi.
- OIR: golden memperlihatkan ekspresi tengah dibuang dan nilai ekor menjadi `return`; kasus return hilang ditolak.
- Native: program memakai ekor blok pada fungsi dan cabang `if`, lalu mencetak `42`.
- Seluruh `claw/tests/run_all_tests.sh` lulus pada salinan disposable (doc-test, frontend, OIR, backend, native).

Catatan ini hanya mencatat slice implicit return. Status PRD tidak diubah; §5 (`try`) tetap parsial dan keseluruhan v0.2 tidak dinyatakan selesai.

## Temuan independen dan koreksi berikutnya

Review read-only independen kemudian mereproduksi leak 16 byte ketika owned temporary `Anchor.new(...)` dibuang sebagai ekspresi non-ekor: OIR hanya mencatat `discard`, bukan destructor. Perbaikan untuk `Anchor`, penolakan owned temporary tanpa destructor yang didukung, serta validasi ASan/LSan dicatat terpisah di [`2026-10-11-v0.2-discarded-owned-temporary-drop.md`](./2026-10-11-v0.2-discarded-owned-temporary-drop.md).

Review independen berikutnya mereproduksi leak 16 byte pada hasil `BinaryExpr` dari overloaded `Add` yang mengembalikan `Anchor[Str]`; allowlist AST sebelumnya tidak mencakup `BinaryExpr`. Klasifikasi type/value-category umum, audit bentuk AST lain, negative cases projection/call, native marker exactly-once, dan validasi dicatat di [`2026-10-11-v0.2-owned-rvalue-discard-cleanup.md`](./2026-10-11-v0.2-owned-rvalue-discard-cleanup.md).

## Status slice setelah koreksi

Status lama “belum dinyatakan siap” menggambarkan tahap sebelum leak `Anchor` langsung dan leak hasil overloaded `Add` diperbaiki. Sesudah kedua koreksi, review independen terarah tidak menemukan blocker; clean configure/build dan seluruh `claw/tests/run_all_tests.sh` dilaporkan lulus di salinan disposable, bersama targeted native ASan/LSan checks untuk cleanup dan evaluasi efek samping tepat sekali. Karena itu, **slice spesifik implicit-return + discarded-owned-rvalue cleanup tervalidasi**. Ini bukan klaim bahwa PRD §3 atau seluruh milestone v0.2 selesai, dan status PRD tidak diubah.
