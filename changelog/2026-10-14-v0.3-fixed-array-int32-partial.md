# 2026-10-14 — Fixed Array `Int32` awal (parsial)

Workstream v0.3 ini menambahkan jalur awal end-to-end untuk literal dan nilai lokal `Array[Int32, N]`. **Perubahan ini parsial; tidak menyelesaikan §2 maupun milestone v0.3, dan PRD tidak diubah.**

## Baseline sebelum edit source

Compiler baseline dibangun dari work branch yang bersih sebelum perubahan source:

```sh
cmake -S claw -B /tmp/cat-fixed-array-baseline -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_COMPILER=clang++
cmake --build /tmp/cat-fixed-array-baseline -j 4
/tmp/cat-fixed-array-baseline/claw check /tmp/cat-fixed-array-baseline.cat
```

Program repro mencoba sekaligus anotasi `Array[Int32, 3]`, literal `[1, 2, 3]`, read-index `values[1]`, serta `scan item, i over values`. Baseline berhenti di parser pada anotasi tipe:

```text
error[parse]: Expected type name
 --> /tmp/cat-fixed-array-baseline.cat:2:30
 2 |     val values: Array[Int32, 3] = [1, 2, 3]
   |                              ^
```

Karena parsing anotasi gagal, literal, indexing, dan scan pada program yang sama tidak mencapai analisis semantik atau backend.

## Perubahan

- Parser menerima literal non-empty `[1, 2, 3]` dan anotasi tipe `Array[Int32, N]`, dengan panjang `N` sebagai integer literal konstan.
- Inferensi menghasilkan tipe `Array[Int32, N]`; panjang menjadi bagian identitas tipe dan mismatch panjang anotasi ditolak.
- Tipe elemen selain `Int32`, elemen literal heterogen, nested arrays, `N == 0`, serta literal kosong ditolak secara semantik.
- LLVM merepresentasikan array sebagai `[N x i32]`; layout dan ABI aggregate mendukung nilai kecil secara langsung dan nilai yang lebih besar lewat ABI tidak langsung.
- Read indexing menerima `USize` dan memancarkan perbandingan unsigned `index < N`, cabang trap, lalu baru `getelementptr inbounds` dan load. Indeks signed dan literal negatif ditolak. OIR menurunkan object dan index satu kali; uji native memverifikasi side effects tetap satu kali dan berurutan.
- Scan biasa dan `scan item, i over array` berjalan dari indeks `USize` nol; loop guard `index < N` mendahului GEP/load setiap item.
- Array global/static dan mutable element assignment (termasuk compound assignment) ditolak eksplisit; tidak ada kontrak store elemen baru.
- Diagnostic indexed scan diperbarui untuk menyebut fixed `Array[Int32, N]` sebagai iterable yang didukung.

## Validasi

- Build final berhasil dengan `cmake -S claw -B /tmp/cat-fixed-array-final -G Ninja -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_COMPILER=clang++` lalu `cmake --build /tmp/cat-fixed-array-final -j 4`.
- `claw check`, `claw oir`, `claw llvm`, dan native build/execution dijalankan terhadap fixture fixed-array.
- Native tests mencakup literal inferred dan annotated, index awal/tengah/akhir, parameter dan return array, evaluation order/side effects, scan biasa/indexed, indeks scan mulai dari 0, serta trap saat `index == len`.
- `Array[Int32, 5]` menguji return/parameter ABI aggregate tidak langsung.
- Frontend negative fixtures mencakup mismatch, tipe elemen, tipe signed/negatif, panjang nol/kosong, nested/global arrays, dan assignment elemen.
- OIR golden dan backend LLVM assertions memastikan layout `[N x i32]` dan guard sebelum GEP/load.
- Full suite `bash claw/tests/run_all_tests.sh` lulus pada salinan disposable; seluruh docs, frontend, OIR, backend, native, dan CLI suites sukses. Artifacts runner berada di salinan, bukan branch.
- Fixed-array native fixture lulus di ASan/UBSan/LSan dengan output identik; defect native `index == len` menghasilkan trap nonzero seperti yang diharapkan.

## Batas yang tersisa

Belum didukung: tipe elemen selain `Int32`, nested arrays, literal ukuran nol, global arrays, mutable element assignment, `Vec`/`Span`/`Set`/`Map`, Arena, serta perubahan kontrak Arena. Tidak ada klaim bahwa seluruh scope PRD §2/v0.3 sudah selesai.
