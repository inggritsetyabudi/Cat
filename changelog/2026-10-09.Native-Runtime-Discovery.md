## Native Runtime Bundling and Working-Directory Independence

### CMake Packaging
- The CMake-built `claw` target now places `runtime/native_runtime.c` beside the compiler under the target's `runtime/` directory.
- The runtime source is a link dependency so changes to it refresh the bundled copy on the next build.
- This uses the executable-adjacent runtime lookup already supported by the native build driver; native builds no longer need to be launched from `claw/` to find the source runtime.

### Regression Coverage
- The native test runner builds and executes a single-file fixture from a temporary directory outside the repository, checking both runtime discovery and generated program output.
- Temporary regression outputs are removed when the runner exits; the established native artifacts remain available for inspection.
