# 2026-10-14 — Fixed Array: overflow ukuran byte

## Masalah dan baseline

Pada branch `work/fixed-array-int32-2026-10-14`, `Array[Int32, 4611686018427387904]` sebelumnya lolos `claw check` pada target 64-bit karena panjangnya muat di `size_t`, walaupun jumlah byte (`N * 4`) overflow. Baseline repro pada diff workstream saat ini mengembalikan exit code 0 untuk `check`; `claw llvm` juga membentuk aggregate `[4611686018427387904 x i32]`.

## Perbaikan

- Menambahkan `fixedArrayByteSize` sebagai batas bersama: perkalian elemen/ukuran byte harus muat baik pada representasi `size_t` host maupun batas ukuran alamat target.
- Type resolver menerima `TargetSpec` aktif dan menolak `Array[Int32, N]` saat resolusi tipe dengan diagnostik `Fixed Array byte size overflows the target size limit.`
- Layout array memakai helper yang sama dan mengembalikan kegagalan bila ukuran tidak representabel.
- Parsing tipe backend LLVM serta ABI layout menggunakan validasi yang sama; lowering menolak tipe tidak valid alih-alih membentuk LLVM aggregate.
- Menambahkan fixture negatif nyata `claw/tests/frontend/fixtures/revise_bad_fixed_array_size_overflow.cat` dan assertion frontend, OIR, backend, serta native build. Assertion backend memastikan tidak ada `[4611686018427387904 x i32]` pada hasil yang gagal.
- Memperluas regresi panjang canonical yang ekuivalen menjadi `12`, `1_2`, `0xC`, `0b1100`, dan `0o14`. Fixture malformed `1__2` dan suffix tetap ditolak.

## Validasi

- Build compiler berhasil dengan CMake.
- Focused frontend, OIR, backend, dan native suites lulus.
- Full `bash claw/tests/run_all_tests.sh` lulus pada salinan disposable setelah clean build dengan CMake/Ninja dan Clang; suite docs, frontend, OIR, backend, native, dan CLI seluruhnya lulus.
- `git diff --check` dijalankan pada worktree akhir.

Perubahan ini hanya memperbaiki batas ukuran fixed-array pada workstream yang ada; PRD, Arena, dan entry point `main` tidak diubah.
