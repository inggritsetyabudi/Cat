# v0.2 — Unary minus Float64

Sebelumnya unary minus diturunkan menjadi `0.0 - value`. Backend LLVM belum dapat merepresentasikan konstanta float tersebut, sehingga fungsi dengan parameter `Float64` lolos `check` tetapi gagal saat native lowering.

OIR dan LIR kini memiliki instruksi unary eksplisit. Backend memakai LLVM `fneg` untuk operand floating-point, `sub 0, value` untuk integer, dan `xor` untuk `not`; tidak ada konstanta floating-point sintetis.

Tes awal memeriksa OIR `neg value : Float64` dan LLVM IR `fneg double`, tetapi belum memanggil fungsi dengan nilai float runtime. Keterbatasan itu ditutup oleh perubahan terpisah yang dicatat di `2026-10-11-v0.2-float-literal-materialization.md`; fixture lanjutannya benar-benar memanggil fungsi dan membandingkan hasil native.

Verifikasi akhir: clean build seluruh target dan full test suite berhasil.
